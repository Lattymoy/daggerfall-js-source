# Patch Notes: One Place to Pick Your UI

## Interface
- The Enhanced/Classic switch is gone from the main menu and from Settings. Pick your UI on **Overhauls → UI Overhaul**: Classic, Enhanced Plus or GrimoireUI.
- Overhauls is on the main menu in both Enhanced Plus and Classic, and in the pause menu under System.
- About shows which UI you're using.

## Behind the scenes
- Leftover code from the old Enhanced UI is removed. Enhanced Plus looks and works the same.
