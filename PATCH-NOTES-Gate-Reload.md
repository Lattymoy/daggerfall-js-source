# Patch Notes: The Oblivion Gate says "reload", not "closed"

## Fixed
- **Thrown out of the Burning Court the moment you enter, told "The gate is closed."** That happens when your game is older than the gate's last update. The gate now tells you so: save, then reload (or update the app).
- Still getting it? Reload the page. On the desktop app for Windows (installed) or Linux, quit and start it again: it installs its update when it closes. On Mac, or the portable Windows build, download the new version when the app tells you one is out.
