# Diverse Weapons

RealAKP's DFU mod Diverse Weapons 1.7.3 (script by RealAKP and Kirk.O, MIT): a first-person sprite set for each weapon
template, where the classic art has one per weapon class. Eighteen weapons in ten metals, plain and enchanted, every
record and frame; Weapon Widget's double-scale idles; inventory and paperdoll icons in every metal; the Wabbajack's own
set. 12,624 sprites ship with the port. It is on by default in the Mods pane. The vendored record is
`vendor/diverse-weapons/`.

## How it works

- **The mod is one line**: it sets DFU's `FPSWeapon.moddedWeaponHUDAnimsEnabled`. Everything that switches on is DFU's
  own, so the port is a port of DFU gated on the mod's switch (`moddedWeaponHUDAnimsEnabled`,
  `src/combat/diverseWeapons/diverseWeapons.js`).
- **The file name** (`moddedWeaponFilename`) is DFU's `WeaponBasics.GetModdedWeaponFilename`: the named artifact
  CIFs, `<NAME>MAGIC.CIF` while enchanted, `<NAME>.CIF`; a custom template answers none. `atlasFileName` is DFU's
  `GetWeaponTextureAtlas` choice. Each frame is asked by DFU's `<FILE>_<record>-<frame>_<Metal>` spelling and drawn
  into the classic record's box. A miss draws the classic frame.
- **Two lanes, one law.** The classic sprite (`src/combat/fpsWeapon.js`, `loadFpsWeaponArt`) and the Weapon Widget
  clone both ask the same functions.
- **The sprites** are under `public/art/diverse-weapons/`, re-encoded from the bundle by
  `tools/diverseWeaponsExtract.mjs` (indexed PNG where it fits, every drawn pixel identical). The door's index
  (`src/combat/diverseWeapons/diverseWeaponsIndex.js`, generated by `tools/diverseWeaponsIndex.mjs`) says which names
  exist, so a miss costs no fetch. A player's own attached `.dfmod` still answers first.
- **The icons.** Weapon icons (archives 233 and 234 by metal, 432 and 433 for the Wabbajack) are asked by DFU's
  `GetItemImage` name with the item's dye, as DFU spells it; Silver asks the bare name.
- **The Weapon Widget preset** (`DIVERSE_WEAPONS_WIDGET_PRESET`, `withDiverseWeaponsPreset`): the mod's recommended
  Weapon Widget settings, laid over the player's own while the mod's `WeaponWidgetPreset` switch is on, so turning it
  off gives theirs back. Weapon Widget's `Enabled` is never in it. Under the preset, the doubled idle's offset applies
  only where the box is really doubled (DoubleScaleTextures without TrueTextureSize, on a `w_` hit).

## Rules

- A mod integration, its sprites in the codebase rather than an attachable file (Mac).
- The preset is off by default, so the mod's sprites move with Weapon Widget's own defaults (Mac).
- A drawn copy wearing a Wardrobe look is no artifact: it swings the look's file (`Wardrobe.md`).
- The doctrine derives the folder's allowed files from the mod's own manifest (`test/tooling/doctrine.test.js`).

## Daggerfall Unity

All of it is DFU's own law (`FPSWeapon`, `WeaponBasics`, `TextureReplacement`, `ItemHelper.GetItemImage`). Departures:
the preset is laid over rather than overwriting; a look copy swings the look's file; the icon key carries the dye,
where the port's texture key once dropped it.
